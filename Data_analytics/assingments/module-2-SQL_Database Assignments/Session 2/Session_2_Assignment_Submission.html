1. Key Concepts

  • SELECT: Identifies which attributes/columns to retrieve from the database.
  • FROM: Identifies the table or relation containing the requested attributes.
  • Selective Projection: Querying specific columns (SELECT col1, col2) improves performance and bandwidth compared to the wildcard (SELECT *).
  • Column Aliasing: The AS keyword provides user-friendly column headers in outputs without modifying the physical table schema.
  • SQL Comments: Single-line comments start with -- (ANSI standard) or # (MySQL). Multi-line comments use /* ... */.
