1. Theoretical Concepts: GROUP BY vs. HAVING vs. WHERE

Clause Pipeline Stage Filter Target Can Use Aggregates?
WHERE Pre-Aggregation (Row-Level) Filters raw rows before grouping ❌ No (Throws syntax error)
GROUP BY Grouping Stage Partitions dataset by categorical columns — (Forms the group boundaries)
HAVING Post-Aggregation (Group-Level) Filters aggregated metrics (e.g. SUM > 1M) ✅ Yes (Specifically built for aggregates)

2. Demo: Total Revenue per Region (Revenue > 1M)

Demo Query 
SELECT region, SUM(revenue) AS total_revenue
FROM regional_sales
GROUP BY region
HAVING SUM(revenue) > 1000000
ORDER BY total_revenue DESC;
