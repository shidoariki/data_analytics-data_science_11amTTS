1. String Operations Summary

Function Description Dialect Behavior
CONCAT(s1, s2) Concatenates multiple string tokens MySQL built-in; SQLite uses pipe || operator
UPPER(s) / LOWER(s) Transforms text case Standard across ANSI SQL
TRIM(s) Strips leading and trailing spaces Standard ANSI SQL
RIGHT(s, n) Extracts last n characters from string end MySQL built-in; SQLite uses SUBSTR(s, -n)
REPLACE(s, from, to) Substitutes character patterns Standard ANSI SQL

2. Assignment Solutions

Demo: Clean Inconsistent Product Codes

SELECT raw_id, raw_code,
       UPPER(TRIM(raw_code)) AS normalized_code,
       REPLACE(UPPER(TRIM(raw_code)), '-', '_') AS cleaned_standard_code
FROM dirty_product_codes;

Task 1: Combine Names with CONCAT()

SELECT user_id,
       CONCAT(first_name, ' ', last_name) AS full_name,
       email
FROM users;

Task 2: Song Titles in Uppercase with UPPER()

SELECT id, song_title,
       UPPER(song_title) AS song_title_upper,
       artist
FROM playlists;

Task 3: Remove Whitespace with TRIM()

SELECT item_id, item_name,
       item_code AS raw_item_code,
       TRIM(item_code) AS cleaned_item_code
FROM food_items;

Task 4: Extract Numeric ID with RIGHT()

SELECT movie_id, title, imdb_id,
       RIGHT(imdb_id, 7) AS movie_number
FROM movies;

Task 5: Replace Delimiters with REPLACE()

SELECT product_id, product_name,
       sku_code AS original_sku,
       REPLACE(sku_code, '-', '_') AS updated_sku_code
FROM products;
