1. Theoretical Concepts: Advanced Join Types

Join Technique Relational Mechanism Industry Use Case
FULL OUTER JOIN Retains all rows from left and right tables; unmatched values return NULL. Marketing audits, partner reconciliation, merging CRM & Billing.
SELF JOIN Joins a table to itself using dual aliasing (e.g. e JOIN m). Employee-manager org trees, nested playlist hierarchies, customer co-residence.
CROSS JOIN Cartesian product of all records ($M \times N$). Recommendation candidate generation, matrix evaluations.

2. Demo: Self Join Employees Table → Manager Relationship

SELECT

    e.name AS employee_name,
    e.department,
    COALESCE(m.name, 'Top Executive / No Manager') AS manager_name

Task 5: AI-Assisted Query: Pairs of Users Living in the Same City

Completed & Verified
AI Debugging Insight: Using u1.user_id < u2.user_id instead of != eliminates reciprocal duplicates (e.g. keeps (Aarav, Kabir) and removes (Kabir, Aarav)). 
SELECT u1.user_name AS user_1, u2.user_name AS user_2, u1.city
FROM users u1
INNER JOIN users u2 ON u1.city = u2.city AND u1.user_id < u2.user_id
ORDER BY u1.city, user_1;
