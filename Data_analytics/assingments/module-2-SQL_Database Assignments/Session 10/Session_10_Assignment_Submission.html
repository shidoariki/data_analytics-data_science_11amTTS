1. Theoretical Concepts: Set Operations in SQL

Set Operator Duplicate Handling Engine Execution Best Used For
UNION Removes duplicate records Performs sorting / hash de-duplication pass (slower) Master customer registries, unique taxonomy lists
UNION ALL Retains all records intact Direct streaming concatenation (optimal speed) Transaction consolidation, audit trails, event streaming

2. Demo: Combine Online + Offline Sales Tables

Demo Query 
SELECT sale_id, customer_name, amount, sale_date, 'Online' AS channel FROM online_sales
UNION ALL
SELECT sale_id, customer_name, amount, sale_date, 'Offline' AS channel FROM offline_sales
ORDER BY sale_date;
