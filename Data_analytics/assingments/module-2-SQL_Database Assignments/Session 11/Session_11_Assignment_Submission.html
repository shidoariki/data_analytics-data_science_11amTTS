1. Theoretical Concepts: Subquery Architecture

Subquery Type Placement Location Return Shape Analytical Purpose
Scalar Subquery SELECT or WHERE 1 Value (1x1) Dynamic threshold filtering (e.g. WHERE salary > AVG) and inline benchmark columns.
Correlated Subquery SELECT or WHERE 1 Value per row Row-dependent metric calculation (e.g. Category Average Price alongside each product).
Derived Table FROM clause Multi-Row Table Two-phase aggregation (e.g. pre-counting items per user before outer filtering).

2. Demo: Employees Earning Above Company Average Salary

Demo Query 
SELECT id, name, department, salary
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees)
ORDER BY salary DESC;

Task 3: Users with More Playlists Than Average (Subquery in FROM & WHERE)

Completed & Verified 
SELECT u.username, user_counts.playlist_count
FROM Users u
INNER JOIN (
    SELECT user_id, COUNT(playlist_id) AS playlist_count
    FROM Playlists
    GROUP BY user_id
) user_counts ON u.user_id = user_counts.user_id
WHERE user_counts.playlist_count > (
    SELECT AVG(sub.p_count)
    FROM (SELECT COUNT(playlist_id) AS p_count FROM Playlists GROUP BY user_id) sub
)
ORDER BY user_counts.playlist_count DESC;
