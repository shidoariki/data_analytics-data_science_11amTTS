1. Theoretical Concepts & SQL Clauses

Clause / Keyword Syntax Pattern Purpose & Analytical Value
DISTINCT SELECT DISTINCT column FROM table Removes duplicate records from projection to reveal unique categories, cities, or payment modes.
ORDER BY ORDER BY col1 [ASC|DESC], col2 ... Sorts the record set alphabetically, chronologically, or numerically (defaults to ASC).
LIMIT LIMIT n [OFFSET m] Restricts output row count to n rows, enabling Top-N analysis and UI pagination.
