1. Theoretical Concepts: Common Table Expressions

CTE Feature Syntax Pattern Analytical Advantage
Non-Recursive CTE WITH CteName AS (SELECT ...) SELECT ... Eliminates nested subqueries, enables sequential pipeline decomposition.
Recursive CTE WITH RECURSIVE Cte(n) AS (Anchor UNION ALL Recursive) Traverses tree structures and dynamically synthesizes date dimensions.
Multiple CTEs WITH Cte1 AS (...), Cte2 AS (...) SELECT ... Chains multiple intermediate data marts within a single query scope.

2. Demo: Year-over-Year (YoY) Sales Growth

Demo Query 
WITH SalesCTE AS (
    SELECT 
        s1.sale_year,
        s1.total_revenue,
        s2.total_revenue AS prev_year_revenue
    FROM annual_sales s1
    LEFT JOIN annual_sales s2 ON s1.sale_year = s2.sale_year + 1
)
SELECT 
    sale_year,
    total_revenue,
    prev_year_revenue,
    ROUND(100.0 * (total_revenue - prev_year_revenue) / prev_year_revenue, 2) AS yoy_growth_pct
FROM SalesCTE
ORDER BY sale_year;

Completed & Verified 
WITH MonthlyTotals AS (
    SELECT strftime('%m', order_date) AS order_month, SUM(total_amount) AS total_sales
    FROM FlipkartOrders
    WHERE strftime('%Y', order_date) = '2023'
    GROUP BY strftime('%m', order_date)
)
SELECT order_month, total_sales
FROM MonthlyTotals
ORDER BY total_sales DESC

Task 3: Recursive CTE Generating Next 7 Calendar Days

Completed & Verified 
WITH RECURSIVE CalendarDays(day_date, day_num) AS (
    SELECT CURRENT_DATE, 1
    UNION ALL
    SELECT DATE(day_date, '+1 day'), day_num + 1
    FROM CalendarDays
    WHERE day_num < 7
)
SELECT day_num, day_date FROM CalendarDays;

Task 4: Restaurants in Cities with City Average Rating > 4.0

Completed & Verified 
WITH CityAvgRatings AS (
    SELECT city, ROUND(AVG(rating), 2) AS city_avg_rating
    FROM ZomatoRestaurants
    GROUP BY city
    HAVING AVG(rating) > 4.0
)
SELECT r.id, r.name, r.city, r.rating, c.city_avg_rating
FROM ZomatoRestaurants r
INNER JOIN CityAvgRatings c ON r.city = c.city
ORDER BY c.city_avg_rating DESC, r.rating DESC;

Task 5: AI-Assisted Query: IPL 2023 Total Runs > 2000

Completed & Verified
AI Architectural Insight: Decomposes temporal scoping (`match_year = 2023`) and aggregation into the CTE, isolating the presentation cutoff (`WHERE total_runs > 2000`) in the outer statement. 
WITH TeamRuns2023 AS (
    SELECT team, SUM(runs) AS total_runs
    FROM IPLMatches
    WHERE match_year = 2023
    GROUP BY team
)
SELECT team, total_runs
FROM TeamRuns2023
WHERE total_runs > 2000
ORDER BY total_runs DESC;
