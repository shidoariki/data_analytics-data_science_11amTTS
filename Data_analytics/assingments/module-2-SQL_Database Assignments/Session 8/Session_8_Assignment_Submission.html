1. Theoretical Concepts: Relational Joins & Keys

Join Type Relational Logic Treatment of Unmatched Rows
INNER JOIN Intersection: Matches records existing in both tables. Unmatched rows from either table are discarded.
LEFT JOIN Preserves all rows from the Left table. Left rows with no right match display NULL for right columns.
RIGHT JOIN Preserves all rows from the Right table. Right rows with no left match display NULL for left columns.

2. Demo: Join Orders + Customers → Customer Segment → Revenue

Demo Query 
SELECT 
    cs.segment_name,
    COUNT(o.order_id) AS total_orders,
    COALESCE(SUM(o.amount), 0.00) AS total_revenue
FROM CustomerSegments cs
LEFT JOIN Users u ON cs.segment_id = u.segment_id
LEFT JOIN Orders o ON u.user_id = o.user_id
GROUP BY cs.segment_id, cs.segment_name
ORDER BY total_revenue DESC;
