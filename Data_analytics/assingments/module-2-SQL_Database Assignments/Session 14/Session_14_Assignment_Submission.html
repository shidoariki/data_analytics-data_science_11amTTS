1. Executive Summary & Concepts

Window ranking functions calculate position indicators over ordered partitions. Their primary behavioral difference lies in how they handle ties:

Function Tie Handling Gaps in Sequence Real-World Usage
ROW_NUMBER() Strictly unique sequence per row No gaps (1, 2, 3, 4) Order chronology, pagination, deduplication
RANK() Shared rank for equal values Leaves gaps (1, 2, 2, 4) Sports tournaments, streaming hits
DENSE_RANK() Shared rank for equal values No gaps (1, 2, 2, 3) Price tiering, customer loyalty brackets

2. Assignment Solutions

Demo: Top 3 Selling Products Per Region

WITH RankedProducts AS (
    SELECT product_id, product_name, region, units_sold,
           DENSE_RANK() OVER (PARTITION BY region ORDER BY units_sold DESC) AS rank_in_region
    FROM regional_product_sales
)
SELECT product_id, product_name, region, units_sold, rank_in_region
FROM RankedProducts
WHERE rank_in_region <= 3
ORDER BY region ASC, rank_in_region ASC;

Task 1: ROW_NUMBER() Sequential Order History

SELECT order_id, user_id, order_date, total_amount,
       ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY order_date DESC) AS order_sequence_desc
FROM Orders
ORDER BY user_id ASC, order_sequence_desc ASC;

Task 2: RANK() Songs by Streams (Demonstrates Gaps)

SELECT song_id, song_title, artist, streams,
       RANK() OVER (PARTITION BY artist ORDER BY streams DESC) AS stream_rank
FROM Songs
ORDER BY artist ASC, stream_rank ASC;

Task 3: DENSE_RANK() Movies by Rating (No Gaps)

SELECT movie_id, movie_name, genre, rating,
       DENSE_RANK() OVER (PARTITION BY genre ORDER BY rating DESC) AS rating_dense_rank
FROM Movies
ORDER BY genre ASC, rating_dense_rank ASC;

Task 4: Top 3 Influencers per Platform

WITH RankedInfluencers AS (
    SELECT id, influencer_name, platform, followers,
           ROW_NUMBER() OVER (PARTITION BY platform ORDER BY followers DESC) AS rank_num
    FROM Influencers
)
SELECT id, influencer_name, platform, followers, rank_num
FROM RankedInfluencers
WHERE rank_num <= 3
ORDER BY platform ASC, rank_num ASC;
