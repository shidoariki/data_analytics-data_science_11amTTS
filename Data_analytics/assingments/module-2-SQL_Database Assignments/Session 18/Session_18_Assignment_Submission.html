1. View Updatability Limits

Observed Error on Aggregate View UPDATE:
ERROR 1288 (HY000): The target table TopRatedRestaurants of the UPDATE is not updatable

A view cannot accept UPDATE, INSERT, or DELETE operations when it includes aggregate functions (AVG, SUM, COUNT), GROUP BY, or multi-table joins where a single base-table target row cannot be unequivocally determined.

2. Assignment Solutions

Demo: Daily Sales Reporting View

CREATE VIEW View_DailySalesDashboard AS
SELECT sale_date,
       COUNT(sale_id) AS total_transactions,
       SUM(amount) AS total_revenue,
       ROUND(AVG(amount), 2) AS avg_ticket_size
FROM daily_sales
GROUP BY sale_date;

Task 1 & 2: TopRatedRestaurants with City Join

CREATE OR REPLACE VIEW TopRatedRestaurants AS
SELECT r.restaurant_name,
       r.city,
       ROUND(AVG(rv.rating), 2) AS avg_rating,
       COUNT(rv.review_id) AS total_reviews
FROM restaurants r
INNER JOIN restaurant_reviews rv ON r.restaurant_id = rv.restaurant_id
GROUP BY r.restaurant_id, r.restaurant_name, r.city
HAVING AVG(rv.rating) > 4.0;

Task 4: DailyOrdersSummary View (Last 30 Days)

CREATE VIEW DailyOrdersSummary AS
SELECT order_date,
       COUNT(order_id) AS total_orders,
       SUM(order_amount) AS total_revenue
FROM swiggy_orders
WHERE order_date >= DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY)
GROUP BY order_date;

Task 5: 3 Best Practices for Analytics Views (Flipkart Scenario)

  1. Pre-filter Scope: Filter order_status = 'DELIVERED' inside the view to avoid scanning cancelled/returned orders.
  2. Standardize Metrics: Pre-calculate ROUND(SUM(sale_amount - discount), 2) AS net_gmv to establish an organizational single source of truth.
  3. Index Base Tables: Index composite columns (order_date, category_id) on underlying tables for sub-second dashboard rendering.
