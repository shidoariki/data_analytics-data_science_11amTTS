1. Theoretical Concepts: SQL Aggregations

Function Definition Analytical Purpose
SUM()Calculates arithmetic total of valuesTotal revenue, total spending, gross order volume.
COUNT()Counts number of rows / non-null recordsOrder frequency, playlist track counts, user signups.
AVG()Computes the arithmetic meanAverage Order Value (AOV), average user rating, average salary.
MIN() / MAX()Retrieves minimum and maximum valuesBoundary analysis, price ranges, highest ticket transactions.
ROUND()Formats numerical precision to n decimalsFinancial reporting, clean dashboard visualizations.

2. Demo: Total Revenue, Average Salary, Highest Order Value

Demo Queries 
-- 1. Total Revenue
SELECT SUM(revenue) AS total_revenue FROM demo_sales;

-- 2. Average Salary
SELECT ROUND(AVG(salary), 2) AS average_salary FROM demo_employees;

-- 3. Highest Order Value
SELECT MAX(order_value) AS highest_order_value FROM demo_orders;
